# LOLPingYourAI v0.1.3 — macOS and Windows

- Question pings explore relevant page content and retrieve context through native harness tools. Explicit observe-only requests and ward visits stay read-only.
- Nearby repeated questions carry expression/tone without starting duplicate work on the same known window. Emotional emotes support playful counter-pings without turning a joke into an edit command.
- Chat shows the request capture and the agent's latest view; replies render Markdown tables, LaTeX and fenced code.
- A generated working emote accompanies streamed output in the inactive floating card, with elapsed time and Retreat. About displays the build commit.
- Includes the upstream wheel sizing, custom emote sounds and desktop fixes, plus native model refresh/latency improvements merged since the previous installers.
- English/Chinese contribution guides, a PR evidence template and a full-matrix release gate now publish both the macOS arm64 DMG and Windows x64 installer.

下载 / Downloads: `LOLPingYourAI-0.1.3-arm64.dmg` (macOS 13+, Apple Silicon) and `LOLPingYourAI-Setup-0.1.3.exe` (Windows x64). Quit other lolPing instances first. The Mac application is ad-hoc signed, not notarized; Windows is unsigned. macOS may require re-associating Accessibility and Screen Recording permission after updating.

Validation: local typecheck, service/protocol and acceptance tests, native helper assertions, real Electron rendering and synthetic performance checks; publication requires all three CI platforms and packaged runtime tests. These checks do not establish every app/monitor layout or real Claude/DSH inference. See [interaction behavior](https://github.com/ChristianYang37/LOLPingYourAI/blob/v0.1.3/docs/interaction-ux.md). Screenshots remain local and bounded; no private captures are included in the release sources.
