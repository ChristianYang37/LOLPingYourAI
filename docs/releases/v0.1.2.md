Windows x64 installer built from current official source, including the chat homepage and PR #11 integration.

- Hardened Windows window identity, bounds/occlusion checks, focus changes during text input, cooperative cancellation and resize readback/rollback.
- Fixed Chinese Windows C++ compilation and enabled the conforming MSVC preprocessor while retaining C++20. Visual Studio 2022 or newer is required to build.
- Added Windows Codex executable/npm-shim discovery and consistent isolated data directories.
- Added real Windows native regressions, Windows 2022/2025 CI, packaged-runtime checks, and NSIS install/start/restart/uninstall testing. Publication is gated on the full CI matrix.
- Verified a real Windows Codex loop on an isolated Test Board: observe/reverse-ping, edit, then restore through Danger, with independent text readback.

Download `LOLPingYourAI-Setup-0.1.2.exe` below. The installer is unsigned and installs per user. Quit other lolPing/LOLPingYourAI instances before starting it.

This is a Windows release; the existing macOS DMG remains available under v0.1.1. See [Windows verification and remaining limits](https://github.com/ChristianYang37/LOLPingYourAI/blob/v0.1.2/docs/windows.md). Mixed-DPI hardware, UAC/lock/sleep, a real 30-minute ward, and authenticated Claude/DSH Windows runs are not claimed as passed.
