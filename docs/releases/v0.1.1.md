# LOLPingYourAI v0.1.1

## English

Download **LOLPingYourAI-0.1.1-arm64.dmg** for Apple Silicon Macs. Quit LOLPingYourAI, open the DMG and replace the app in Applications. On first launch, check Accessibility and Screen Recording permissions. An ad-hoc-signed update may require removing the old permission entry and adding the updated application again.

- Select a harness and load its available models. Model choices are saved per harness; fast mode defaults to off and is offered only where supported.
- Add DeepSeek Harness (DSH) through ACP. Thinking is enabled by default, with native effort selection and a separate off switch. DSH ACP currently exposes no fast-mode control. See [DSH setup](../dsh.md).
- Add the teammate reply card, follow-up input, task status, setup guidance and ward controls.
- Improve macOS targeting of overlapping windows, stale-coordinate rejection and interruption handling.
- Apply the supplied logo to the application icon and settings branding.

Validation: macOS/Windows CI covers typechecking, automated tests, native helpers, application builds and packaged runtime checks. The Apple Silicon package is also checked locally for SDK import, native Claude CLI startup, sharp image processing and code-signature integrity. See [dated verification evidence](../verification.md).

Windows hardware and authenticated Claude desktop use remain unverified. Earlier DSH desktop evidence used the preceding helper and thinking off; it does not establish a full end-to-end test of the new defaults. This release does not include the reverted external SDK upgrade or its unverified acceptance claims.

## 中文

Apple Silicon Mac 请下载 **LOLPingYourAI-0.1.1-arm64.dmg**。退出 LOLPingYourAI，打开 DMG，将应用替换到「应用程序」。首次启动后检查辅助功能和录屏权限；临时签名的更新可能需要移除旧权限条目，再添加新版应用。

- 选择 harness 后加载其可用模型，分别保存模型选择；快速模式默认关闭，仅在后端支持时提供。
- 新增 DeepSeek Harness（DSH）的 ACP 接入。思考默认开启，原生思考档位和关闭开关分开；DSH ACP 目前不提供快速模式控制。配置见 [DSH 指南](../dsh.md)。
- 新增队友回复卡片、追问、任务状态、首次设置引导和插眼回访管理。
- 改进 macOS 重叠窗口定位、过期坐标拒绝和任务中断处理。
- 应用图标和设置界面统一使用新 logo。

macOS／Windows CI 检查类型、自动测试、原生 helper、构建和安装包运行依赖；Apple Silicon 安装包另经本机 SDK 加载、Claude CLI 启动、图片处理和签名检查。详见[实测记录](../verification.md)。

Windows 实机及 Claude 登录后的桌面操作仍未验证。此前 DSH 桌面实测使用旧 helper 且关闭思考，不能视为新版默认设置的完整闭环验证。本次不包含已撤销的外部 SDK 升级及其未经独立验证的验收声明。
